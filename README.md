# Cylinder_moving_in_fluid

Let us place a cylinder in a perfect (non-viscous) fluid at rest, and set it in motion at a constant speed. The fluid, disturbed by the moving cylinder, then becomes the site of an unsteady flow. In other words, the velocity varies over time at every point in the fluid. In this case, the trajectory of a fluid particle no longer coincides with a streamline. This simulation serves to illustrate the differences inherent in these concepts.
